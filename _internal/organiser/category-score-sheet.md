# Independent category score sheet

Proposed local template, not an official MLH numerical rubric. Use only after
the organiser approves the category criteria and award process. Copy one sheet
per judge, project and eligible entered category into private storage.
Never commit completed sheets.

This file covers the two AI categories only. Use the separate
[PrimeCloud sheet](./primecloud-score-sheet.md) for Best Project Deployed on
PrimeCloud; do not combine category totals.

## Scale and arithmetic

| Rating | Meaning |
|---|---|
| 0 | Not demonstrated |
| 1 | Very poor |
| 2 | Below expectations |
| 3 | Meets expectations |
| 4 | Very good |
| 5 | Excellent |

Weighted points = (integer rating / 5) × criterion weight.
Sum six weighted values for a category total out of 100.
There are no formulas or automatic rankings in this template.

Complete the sheet independently. Organisers manually consolidate valid,
non-conflicted reviews separately for each category, with at least two reviews
per contender. Each judge has equal weight; compare unrounded averages and
correct incomplete marks rather than treating blanks as zero. Follow approved
category tie and prize-allocation rules. Local overall assessment uses the
[separate retained CSV](./judge-score-sheet.csv), not these category weights.

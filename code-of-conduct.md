# Code of Conduct

This event follows the **[MLH Code of Conduct](https://static.mlh.io/docs/mlh-code-of-conduct.pdf)** in full. By registering, checking in, or attending, every participant, mentor, judge, sponsor representative, and organizer agrees to uphold it.

In short, MLH's code asks everyone to:

- Treat each other with respect — no harassment, discrimination, or disruptive behavior, in person or online
- Look out for each other, especially newcomers and beginners
- Follow the instructions of organizers and venue staff
- Report anything that makes you or someone else feel unsafe

This summary doesn't replace the full document — read the [official MLH Code of Conduct (PDF)](https://static.mlh.io/docs/mlh-code-of-conduct.pdf) for the complete policy, including how MLH itself handles reports.

## Reporting a concern at this event

If something happens at the venue that makes you uncomfortable or unsafe:

- Find any **organizer wearing an iTech Club lanyard**, or flag down a mentor — they will either help directly or escalate immediately.
- You can also email the event host: see **Contact Host** on the [official MLH event page](https://events.mlh.com/events/14735-hacktoberfest-hack-day-nairobi-x-itech-club).
- For anything you'd rather report directly to MLH, see the contact details in the [Code of Conduct document](https://static.mlh.io/docs/mlh-code-of-conduct.pdf) itself.

Reports are taken seriously and handled discreetly. Organizers can disqualify any individual or team for Code of Conduct violations, independent of the competition rules — see [Rules → Disqualification]({{ site.baseurl }}/rules/#disqualification).
